# WEB-01 browser screenshots

Model-only screenshots from the production build of the independent SOL-01 web
player, 2026-10-03. Desktop: 1440×1000; mobile: Pixel 7 emulation with touch/DPR,
not a photograph or physical-device GPU benchmark. Headless Chrome/SwiftShader.
Downscaled JPEG review copies; full PNGs are generated under `tmp/` and CI artifacts.
